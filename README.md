# OpenTrainSimulator
Attempt in making a multiplayer train simulator. This project is still in the extremely early phase, and may
never be completed based on the author's time and personal interests.

## AI Usage
AI assisted programming is allowed in the project without having to disclose specific usage in PR. 
You are still responsible for the quality of the code, and such will be checked in PRs. 
"The AI generated it so we must merge it" is not an excuse.
